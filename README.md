# Revision code and numerical data

This package accompanies Revised_Manuscript.docx and Response_to_Reviewers.docx.
It contains newly reconstructed calculations, not the original submitted FEM code.
All reported forces are numerical results, not new experimental measurements.
The manuscript's public repository deposition is outstanding. No DOI is assigned.

## Environment used
Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8.
Intel Xeon Platinum 8370C at 2.80 GHz; Linux shared virtual machine.
All physical inputs in the Python modules are SI units. The convenience cone()
function takes its half-angle in degrees. Relative permeability is dimensionless.

## Reproduction
Run these commands in the unpacked package directory with the above dependencies:

    python numerics.py
    python run_fem.py
    python run_fem_optfit.py
    python reproduce_extras.py
    python make_figures.py

numerics.py regenerates results.json: force components, quadrature convergence,
unequal-cone unreduced checks, Vokoun cylinder checks, shape comparisons,
dimensionless optimisation, stiffness and far-field curves.
run_fem.py regenerates fem_results.json: core convergence, optimum-geometry
gap checks, finite-permeability sensitivity and exterior-grid sensitivity.
run_fem_optfit.py regenerates fem_optfit.json: angular samples and mesh-refined
local polynomial estimates. These are the optimum-angle results used in the paper.
reproduce_extras.py regenerates fem_reference_gaps.json, additional_checks.json
and timing.json. Timings are machine/load dependent and will differ when rerun.
make_figures.py regenerates the revised Figures 4–11. Original Figures 1–3 remain
in the manuscript and are not regenerated by this revision package.

The JSON files preserve unrounded numerical results. CSV files provide convenient
flat exports of selected arrays. Every FEM result includes actual node/element
counts and its mesh/domain settings. Internal close-contour force diagnostics
are retained, but are NOT the production force estimator: the manuscript uses
the complete half-domain Maxwell-stress boundary integral stored as `force`.
The opposing-field statistics omit cut elements and are not coercivity limits.

## Model scope and benchmark
The charge model prescribes uniform polarisation with mu_r=1. The new FEM permits
linear recoil permeability with a fixed remanent source and self-consistent field.
It does not model irreversible demagnetisation, grade-specific hysteresis or
manufacturing defects. The half-domain FEM is for identical mirror-symmetric
repulsive cones. Unequal and asymmetric cases are checked using charge quadrature.

The independent cylinder check evaluates Eq. (4) of Vokoun et al. (2009),
Magnetostatic interactions and forces between cylindrical permanent magnets,
JMMM 321, 3758–3763, DOI 10.1016/j.jmmm.2009.07.030, rewritten in stable
decaying-exponential form and with sign reversed for repulsion. It reproduces
the published theoretical formulation; it is not a new experimental benchmark.
